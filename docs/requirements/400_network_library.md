## 배경 / 목적

axios 기반 HTTP 클라이언트. **네 패키지 중 유일하게 React 에 의존하지 않는다.**
원본은 전역 axios 인스턴스와 앱 전역 타입(`IAxiosResponse`, `$http`)에 묶여 있었고, 이를 전부
옵션 주입으로 뒤집었다 — 인증 토큰·401 처리·응답 봉투 해제를 라이브러리가 결정하지 않는다.

남은 문제:

- `removeUndefined` 가 **이름과 달리 공백 문자열도 지운다.** 의도된 동작이지만 이름이 좁게 읽힌다.
- 재시도·타임아웃·취소 같은 실전 기능이 없다. 있어야 하는지부터 판단이 필요하다.
- ESM 전용이라 Node 백엔드(CJS)에서 쓸 수 없다. 이 패키지는 특히 그 요구가 나올 수 있다.

## 요구사항 (수용 기준)

| ID  | 요구사항                       | 수용 기준                                                       |
| --- | ------------------------------ | --------------------------------------------------------------- |
| N1  | 이름이 동작을 정확히 말한다    | 공개 export 중 이름과 동작이 어긋나는 것이 없다                 |
| N2  | React 비의존이 유지된다        | react 미설치 환경에서 테스트가 통과한다 (**완료**)              |
| N3  | 정책이 전부 주입 가능하다      | 인증·401·봉투·헤더를 라이브러리가 결정하지 않는다 (**완료**)    |
| N4  | 사용법을 문서에서 볼 수 있다   | 옵션별 예제와 "이건 라이브러리가 안 한다" 목록이 문서에 있다    |
| N5  | 실전 기능의 범위가 정해져 있다 | 재시도·취소·업로드 진행률을 넣을지/뺄지 근거와 함께 문서에 있다 |

## 영향 범위

- `packages/network` 전체
- `apps/playground` 의 `/network` 화면
- 배포물: `removeUndefined` 개명은 breaking (미배포라 지금이 가장 쌈)

## 제약 / 비고

- `axios` 는 **필수 peer** 다.
- 런타임 정책을 패키지가 결정하지 않는다는 원칙을 깨지 않는다. 기능 추가 시 항상 **옵션**으로 넣는다.
- ESM 전용 정책은 [rules 03](../rules/03_PUBLISHING_AND_VERSIONING.md) 을 따른다.
