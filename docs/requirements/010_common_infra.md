# 010. 공통 인프라 (트랙 0)

- 로드맵: [ROADMAP](../ROADMAP.md)
- 하위 트랙: [0-1 테스트·CI](../plans/011_common_test_ci.md) · [0-2 규약 문서](../plans/012_common_rules.md) · [0-3 검증 자동화](../plans/013_common_verify_automation.md)

## 배경 / 목적

패키지 4종에 공통으로 걸리는 기반이다. 특정 패키지에 속하지 않지만, 없으면 **모든 트랙의 작업이
회귀에 노출된다.**

지금 상태의 구멍:

- 회귀 테스트 56건은 깔았지만 **`Tx*` 27종의 렌더 테스트가 0건**이고 커버리지 측정이 없다.
- **CI 가 없다.** `pnpm check` 를 사람이 기억해서 돌려야 한다.
- `docs/rules/` 6종 중 **1종만 작성**돼 있다. 나머지는 "(예정)" 상태다.
- 소비자 환경 실검증(001 검증 §5)이 **수동**이라 재현에 2분 걸리고, 잊으면 안 돈다.

## 요구사항 (수용 기준)

| ID  | 요구사항                       | 수용 기준                                                              |
| --- | ------------------------------ | ---------------------------------------------------------------------- |
| C1  | push 마다 검증이 자동 실행된다 | GitHub Actions 에서 `pnpm check` + `pnpm build` 가 돌고 실패 시 막힌다 |
| C2  | 커버리지를 측정한다            | `pnpm test:coverage` 로 패키지별 수치가 나온다                         |
| C3  | 규약이 문서로 있다             | `docs/rules/` 의 "(예정)" 항목이 0개다                                 |
| C4  | 소비자 실검증이 자동이다       | 명령 하나로 pack → 설치 → typecheck/build → 격리 검사가 돈다           |

## 영향 범위

- 신규: `.github/workflows/`, `docs/rules/*`, 검증 스크립트
- `packages/*`: 테스트 파일 추가 외 소스 변경 없음
- 배포물: 영향 없음

## 제약 / 비고

- CI 는 Node `24.14.0` / pnpm `10` 을 고정한다. 로컬과 다르면 CI 가 잡아야 할 문제를 못 잡는다.
- 소비자 실검증은 `npm pack` + `file:` 설치로 한다. **npm publish 없이 가능하다** (001 검증 §5 에서 확인).
