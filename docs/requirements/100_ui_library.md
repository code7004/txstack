## 배경 / 목적

`Tx*` 27종. 4개 패키지 중 가장 크고, 나머지 셋을 합친 것보다 표면적이 넓다.
**여기서 정해지는 규약(테마·props 이름·문서 형식)이 다른 패키지의 기준이 된다.**

원본 3개 저장소에서 추출하며 도메인 지식과 앱 전역 의존은 걷어냈지만, 아직 남은 것들이 있다.

- `TxCoolTable` 이 `@deprecated` 상태로 남아 있고, 경고가 **렌더마다** 찍힌다.
- `TxTooltip` 은 폴더명(`TxToolTip`)과 export 이름이 어긋난다.
- eslint a11y 룰 2개가 꺼져 있다.
- 컴포넌트 렌더 테스트가 0건이다 — 스토리는 있지만 자동 검증은 아니다.

## 요구사항 (수용 기준)

| ID  | 요구사항                        | 수용 기준                                                                |
| --- | ------------------------------- | ------------------------------------------------------------------------ |
| U1  | 알려진 결함이 없다              | 1-1 의 job 이 전부 닫히고 `pnpm check` 통과                              |
| U2  | 공개 API 이름이 일관된다        | 컴포넌트·props 인터페이스·테마 이름 규칙이 27종에서 동일하다             |
| U3  | 렌더 회귀를 자동으로 잡는다     | 주요 컴포넌트의 렌더/상호작용 테스트가 있고 CI 에서 돈다                 |
| U4  | props 를 문서에서 볼 수 있다    | Storybook autodocs 27종 (**완료**)                                       |
| U5  | 소비자가 첫 화면까지 갈 수 있다 | 설치 → Tailwind `@source` → 첫 컴포넌트 경로가 화면으로 존재한다         |
| U6  | 예제를 복붙할 수 있다           | playground 각 화면에서 그 화면을 만든 코드를 볼 수 있다                  |
| U7  | 카탈로그가 배포된다             | 정적 사이트로 호스팅된다                                                 |
| U8  | 앱 가정이 남아 있지 않다        | 도메인 필드명·앱 컴포넌트 하드코딩 0건 (`useTxAgGridOption` 재설계 포함) |

## 영향 범위

- `packages/ui` 전체
- `apps/storybook` · `apps/playground`
- 배포물: 공개 API 가 바뀌면 changeset 필수

## 제약 / 비고

- **Tailwind 클래스 문자열이 테마다.** 런타임 CSS 로 바꾸는 변경은 소비자 설정(`@source`)을 깨뜨린다.
- 무거운 선택적 의존(ag-grid, react-day-picker)의 **subpath 격리를 깨지 않는다.**
- 컴포넌트가 패키지 배럴(`".."`)에서 값을 import 하지 않는다 — 순환이 생긴다 (2026-08-19 에 41파일 수정).
