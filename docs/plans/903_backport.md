# 9-3. 원본 3개 저장소 역이식

- 요구사항: [900 배포](../requirements/900_release.md) — P5 / 기존 요구사항 `002`
- 선행: 9-2 (배포된 패키지가 있어야 소비할 수 있다)
- 상태: 대기
- 원본 3개 저장소는 **이 PC 에 있다** (`/w/Projects/{black-message,usertics,chain-wallet-service}`).

## 목표

`black-message` · `usertics` · `chain-wallet-service` 가 각자 들고 있던 `src/core` 복사본을 지우고
npm 의존으로 바꾼다. **이것이 원래 이 프로젝트를 시작한 이유다** — 한쪽에서 고친 버그가 나머지에
반영되지 않는 문제를 없애는 것.

각 저장소에서 빌드·타입체크 통과 + 주요 화면 수동 확인. 결과는 `docs/verification/903_*.md`.

## 비고

- **원본 저장소를 이 작업 전까지 수정하지 않는다** 는 기존 제약은 이 트랙에서 해제된다.
  다만 저장소별로 별도 브랜치·PR 로 진행한다.
- 파일럿에서 "라이브러리에 없는 것" 이 반드시 나온다. 그때는 라이브러리를 고치고 알파를 하나 더 올린다.
  급하다고 소비 앱에 우회 코드를 넣으면 복사본 문제가 다시 시작된다.
