# 3-1. `@txstack/route-meta` 기본

- 요구사항: [300 @txstack/route-meta](../requirements/300_route_meta_library.md)
- 제품 정의: [000 §2-4](../requirements/000_product_definition.md) — **API 방향 확정 (2026-08-19)**
- 상태: 대기

## 목표

`000 §2-4` 에서 확정한 API 방향을 구현하고, 아직 근거가 없는 정책들을 판정한다.

확정된 것 — **계층형 경로 맵** · **팩토리 + 훅** · **GNB 컴포넌트는 패키지에 넣지 않음**.

## job

### A. 경로 맵과 팩토리 (확정분 구현)

| ID    | job                                              | 담당 | 완료 기준                                                                             |
| ----- | ------------------------------------------------ | ---- | ------------------------------------------------------------------------------------- |
| R1-01 | `createRoutes()` 팩토리 시그니처 설계 (API 승인) | 🤝   | 반환 형태(`{ routes, paths, useRoutePath }`)를 예제 코드로 먼저 적고 승인             |
| R1-02 | 계층형 `paths` 타입 구현                         | 🤖   | `[K in keyof T]` 형태 유지. 중간 노드는 예약 키 `$`                                   |
| R1-03 | `paths` 런타임 구현                              | 🤖   | 순수 객체. `String` 객체 트릭을 쓰지 않는다                                           |
| R1-04 | **F12 추적 회귀 테스트**                         | 🤖   | tsc 심볼 해석으로 원본 선언에 착지하는지 자동 확인. 평탄화로 되돌아가면 실패해야 한다 |
| R1-05 | 오타 검출 타입 테스트                            | 🤖   | 없는 키 접근 시 컴파일이 깨진다                                                       |
| R1-06 | `useRoutePath()` 훅 (팩토리가 생성)              | 🤖   | 반환 타입이 구체 타입이다. 패키지에서 독립 export 하지 않는다                         |
| R1-07 | playground 를 `createRoutes()` 로 전환           | 🤖   | `: RouteTree` 주석이 사라진다. 우리 예제가 목표를 깨지 않는다                         |

> `R1-04` 가 이 트랙의 핵심 안전장치다. 평탄화는 자동완성·오타 검출이 되면서 **추적만** 안 되므로,
> 사람 눈으로는 회귀를 알아채기 어렵다.

### B. 정책 판정 (판단이 먼저)

| ID    | job                                      | 담당 | 완료 기준                                                                      |

| R1-09 | 절대경로 `path` 강제 정책 재검토         | 🤝   | 상대경로 중첩을 쓰는 소비자를 받을지 정한다                                    |

| R1-11 | `meta.onClick` 제거                      | 🤖   | 세 저장소 어디서도 안 쓴다 (실측 확인). 제거 + changeset                       |
| R1-12 | R1-08~10 결정 적용 + changeset           | 🤖   | 정책 변경은 대체로 breaking 이다                                               |
