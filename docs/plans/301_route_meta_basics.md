# 3-1. `@txstack/route-meta` 기본

- 요구사항: [300 @txstack/route-meta](../requirements/300_route_meta_library.md) — R1 · R3
- 상태: 대기

## 목표

이 패키지에 박혀 있는 **정책들**이 범용 라이브러리로 타당한지 하나씩 판정한다.
코드를 고치기 전에 판단이 먼저다.

## job

### 정책 재검토 (판단이 먼저)

| ID    | job                                              | 담당 | 완료 기준                                                          |
| ----- | ------------------------------------------------ | ---- | ------------------------------------------------------------------ |
| R1-01 | index route 미사용 정책의 근거 확인·기록         | 🤝   | 왜 안 쓰는지, 소비자가 필요하면 어떻게 하는지가 문서에 남는다      |
| R1-02 | 모든 노드에 절대경로 `path` 강제하는 정책 재검토 | 🤝   | 상대경로 중첩을 쓰는 소비자를 받을지 정한다                        |
| R1-03 | 권한 모델(`permission?: string`) 재설계 판단     | 🤝   | 다중 권한·역할 조합을 받을지. 받으면 API 형태를 예제로 먼저 적는다 |
| R1-04 | R1-01~03 결정 적용 + changeset                   | 🤖   | 결정대로 반영. 정책 변경은 대체로 breaking 이다                    |

### 테스트 보강

| ID    | job                                           | 담당 | 완료 기준                                                 |
| ----- | --------------------------------------------- | ---- | --------------------------------------------------------- |
| R1-05 | `useCurrentRouteNode` 테스트                  | 🤖   | 중첩 경로·동적 세그먼트에서 올바른 노드를 찾는지 고정된다 |
| R1-06 | `RouteRenderer` 테스트                        | 🤖   | 트리에서 실제 라우터가 파생돼 렌더되는지 검증된다         |
| R1-07 | `enabled: false` 가 children 까지 막는지 검증 | 🤖   | 부모 비활성 시 자식 처리 방식이 테스트로 고정된다         |
| R1-08 | 빈 트리·단일 노드 등 경계 케이스              | 🤖   | 죽지 않고 빈 배열을 돌려준다                              |

## 검증

- `pnpm check`
- playground 좌측 메뉴가 여전히 정확히 파생되는지 확인 (선언 14개 → 노출 11개)
- 결과는 `docs/verification/301_*.md`

## 비고

R1-01~03 은 **전부 판단 job 이다.** 이 패키지는 네 개 중 가장 의견이 강해서,
"원본 앱에서 그렇게 썼으니까" 가 범용 라이브러리의 근거가 되지 못한다.
근거를 못 대는 정책은 옵션으로 열거나 제거하는 쪽을 검토한다.
