# 4-1. `@txstack/network` 기본

- 요구사항: [400 @txstack/network](../requirements/400_network_library.md) — N1

## 목표

이름과 동작이 어긋나는 공개 export 를 없앤다. 배포 전이라 개명 비용이 0 이다.

## 비고

`N1-08` 이 미묘하다. "런타임 정책을 패키지가 결정하지 않는다" 가 이 패키지의 원칙인데
`withCredentials: true` 는 기본값으로 정책을 정하고 있다. 원칙을 지킬지, 실용을 택할지 판단이 필요하다.
