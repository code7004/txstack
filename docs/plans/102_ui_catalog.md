# 1-2. `@txstack/ui` 카탈로그 · 문서

- 요구사항: [100 @txstack/ui](../requirements/100_ui_library.md) — U4 · U5 · U6 · U7
- 선행: [003 계획](003_component_catalog_and_guide.md) P0·P1 (완료)
- 상태: 진행 중 (Storybook 27종 등재 완료 / 나머지 대기)

## 목표

카탈로그를 **소비자가 실제로 쓸 수 있는 문서**로 만든다. 그리고 그 전에,
**사용자가 Storybook 을 직접 구축할 수 있는 상태**를 만든다.

## A. 직접 구축 (학습) — 최우선

> 배경: 지금의 Storybook 은 Claude 가 한 번에 세웠다. 동작은 하지만 **사용자가 구조를 파악하지 못한 채**
> 자산만 생긴 상태다. 앞으로 컴포넌트를 추가할 때마다 Claude 에 의존하게 된다.
>
> 방침(2026-08-19 확정) — **구성은 남기고 스토리 파일만 비운다.**
> `apps/storybook` 의 설정(main.ts · preview.tsx · Tailwind · alias)은 그대로 두고,
> 컴포넌트 1~2개의 `.stories.tsx` 를 지워 사용자가 처음부터 작성한다.
> 설정까지 다시 세우는 것은 배우는 양에 비해 시간이 많이 들고, 27종 스토리를 다시 맞춰야 한다.

| ID    | job                                                 | 담당 | 완료 기준                                                                    |
| ----- | --------------------------------------------------- | ---- | ---------------------------------------------------------------------------- |
| U2-01 | `docs/rules/06_STORYBOOK_SETUP.md` 작성 (= `C2-05`) | 🤝   | 구성의 조각들이 **왜 필요한지** 읽고 이해된다. 레시피가 아니라 계약을 적는다 |
| U2-02 | `TxSpinner.stories.tsx` 삭제 → 사용자가 직접 작성   | 🧑   | 스토리 3종이 뜬다. props 없는 가장 단순한 컴포넌트로 **뼈대**를 익힌다       |
| U2-03 | U2-02 리뷰 · 차이점 짚기                            | 🤝   | 기존 버전과 비교해 무엇이 다르고 왜인지 확인한다                             |
| U2-04 | `TxCheckBox.stories.tsx` 삭제 → 사용자가 직접 작성  | 🧑   | `args`·`argTypes`·제어 컴포넌트 래퍼·`variant` 나열을 직접 해본다            |
| U2-05 | U2-04 리뷰 · autodocs 결과 확인                     | 🤝   | props 표가 타입에서 자동 생성되는 것을 눈으로 확인한다                       |
| U2-06 | 세 번째 컴포넌트를 스스로 고르기 (선택)             | 🧑   | 막히지 않으면 이 단계는 건너뛴다                                             |

### 왜 이 두 개인가

| 컴포넌트     | 배우는 것                                                                          |
| ------------ | ---------------------------------------------------------------------------------- |
| `TxSpinner`  | 파일 위치 · `meta`/`export default` · `StoryObj` · 가장 단순한 스토리 형태         |
| `TxCheckBox` | `args`/`argTypes` 컨트롤 · 제어 컴포넌트를 훅 규칙 위반 없이 감싸는 법 · 변형 나열 |

`TxSpinner` 는 props 가 거의 없어 **뼈대만** 남고, `TxCheckBox` 는 상태·변형·테마가 다 있어
**실전 형태**가 된다. 둘을 하면 나머지 25종은 같은 패턴의 반복이다.
