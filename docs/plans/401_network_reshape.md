# 4-1. `@txstack/network` 축소

- 요구사항: [400 @txstack/network](../requirements/400_network_library.md) — N1~N5
- 제품 정의: [000 §2-2](../requirements/000_product_definition.md)
- 상태: 대기
- ⚠ 이 트랙은 **기능 추가가 아니라 제거**가 본체다. `docs/plans/401_network_basics.md` 를 대체한다

## 목표

HTTP 클라이언트를 걷어내고 axios 플러그인 둘만 남긴다. 11개 export → 3~4개.

## 비고

- **A 를 먼저 끝낸다.** 남길 것을 다듬으면서 제거하면 무엇이 왜 남았는지 흐려진다.
- `N1-07` · `N1-12` 는 판단 job 이다. 공개 API 형태는 승인 후에 구현한다.
- 걷어낸 코드를 **버리지 않는다.** `N1-17` 의 레시피가 그 자리다.
  프로젝트마다 달라야 하는 것이므로, 복사본이 갈라져도 문제가 되지 않는다.
