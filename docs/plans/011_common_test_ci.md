# 0-1. 테스트 · CI

- 요구사항: [010 공통 인프라](../requirements/010_common_infra.md) — C1 · C2

## 목표

`pnpm check` 를 사람이 기억해서 돌리는 상태를 끝낸다. push 하면 자동으로 돌고, 커버리지 수치가 보인다.

## 검증

- 일부러 테스트를 깨뜨린 커밋을 push 해 CI 가 **빨간불이 되는지** 확인한다. 초록불만 보고 끝내지 않는다.
- 결과는 `docs/verification/011_*.md` 에 기록한다.

## 비고

`pnpm check` 는 이미 lint + typecheck + test 를 포함한다. CI 는 여기에 `build` 만 더하면 된다.
검증 항목을 CI 에 새로 만들지 말고 **로컬 명령과 같은 것을 돌린다** — 다르면 "로컬에선 되는데" 가 생긴다.
