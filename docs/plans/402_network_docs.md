그걸 모르면 "왜 401 처리가 없냐" 는 오해가 생긴다.

## 검증

README 예제를 react 미설치 Node 픽스처에서 실행한다 — React 비의존이 문서에서도 사실인지 확인.

## 비고

`N2-05` 는 이 패키지에서 특히 중요하다. React 비의존이라 **Node 백엔드에서 쓰려는 시도**가 나오는데,
ESM 전용이라 CJS `require()` 가 실패한다. Node 가 내는 메시지(`No "exports" main defined`)는 원인을 알려주지 않는다.
