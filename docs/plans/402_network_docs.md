## 비고

`N2-02` 가 이 문서의 핵심이다. 축소 전에는 "왜 401 처리가 없냐" 는 오해였지만,
축소 후에는 **"왜 클라이언트가 없냐"** 가 된다. 답은 "3개 저장소의 백엔드 규약이 서로 달라서
공유될 수 없었다" 이고, 이 근거를 문서에 남겨야 나중에 같은 논의를 반복하지 않는다.
