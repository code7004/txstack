## 3. 검증 과정에서 발견한 결함

| #   | 결함                                                         | 심각도 | 상태                                     |
| --- | ------------------------------------------------------------ | ------ | ---------------------------------------- |
| 1   | `packages/ui` 41개 파일이 패키지 배럴에서 값을 import (순환) | 높음   | ✅ 수정 (`refactor(ui): …` 커밋)         |
| 2   | props 인터페이스 3종 미export                                | 중     | ✅ 수정 (changeset `lucky-props-export`) |
| 3   | `tags: ["autodocs"]` 가 동작하지 않음                        | 중     | ✅ 수정 — `@storybook/addon-docs` 추가   |

### 3-1. 순환 import (결함 1)

Storybook 을 처음 띄우자마자 `Cannot access 'TxClassBorderColor' before initialization` 으로 죽었다.
컴포넌트가 자기 패키지 배럴(`".."`)에서 **값**을 가져오는데, 배럴은 다시 모든 컴포넌트를 내보내므로 순환이다.

playground 는 배럴로 진입해 초기화 순서가 우연히 맞았다. Storybook 은 컴포넌트를 **직접** 진입점으로
삼아 순서가 뒤집히면서 드러났다.

> **이것이 카탈로그의 검증 가치다.** 컴포넌트를 독립적으로 렌더하는 행위 자체가 배럴 진입에서만
> 통하던 가정을 깨뜨린다. 통합 데모(playground)로는 영원히 못 잡는 종류다.

### 3-2. props 인터페이스 미export (결함 2)

`TxCapsLockCheck` · `TxSpinner` · `TxTooltip` 이 props 인터페이스를 선언만 하고 내보내지 않았다.
스토리에서 `Meta<typeof X>` 를 이름 지을 수 없어 `TS4023` 으로 드러났다. 소비자가 래퍼를 만들 때도
같은 문제를 겪었을 것이다.

### 3-3. autodocs 미동작 (결함 3)

`tags: ["autodocs"]` 를 달았는데 `/index.json` 의 docs 항목이 **0개**였다. Storybook 10 은 docs 를
별도 패키지로 분리했고, `@storybook/addon-docs` 를 등록해야 동작한다. 등록 후 27개가 생성됐다.

> 스토리에 태그만 달고 넘어갔다면 **R2 를 충족했다고 착각한 채** 끝났을 것이다.
> 수용 기준은 "태그를 달았다" 가 아니라 "docs 페이지가 생성됐다" 로 확인해야 한다.

## 4. 미수행 / 한계

- **스크린샷 없음** — 브라우저 패널이 표시되지 않는 환경이라 DOM·계산된 스타일로 검증했다.
  시각적 회귀(레이아웃 깨짐, 색 대비)는 이 방법으로 잡히지 않는다.
- **상호작용 검증 없음** — 스토리가 렌더되는 것까지만 확인했다. 클릭·입력 시나리오는 `play` 함수나
  `@storybook/addon-vitest` 를 붙여야 자동화된다.
- 다크모드는 툴바 토글이 동작하는 것만 확인했고, 27종 전부를 다크 상태로 훑지는 않았다.
- P2(가이드 화면) · P3(예제 코드 노출) · P4(정적 배포) 미수행.
