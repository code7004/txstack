## 규약을 바꾸는 절차

규약은 코드보다 위에 있다. 코드가 규약과 어긋나면 **코드를 고치는 게 기본**이다.
규약 자체를 바꿔야 한다면:

1. 왜 현재 규약이 틀렸는지를 해당 문서의 "미결/변경 이력" 절에 적는다.
2. 사용자 승인을 받는다.
3. 규약 문서를 먼저 고치고, 그 다음 코드를 고친다.
