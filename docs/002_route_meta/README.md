# 002 — `@txstack/route-meta`

> **한 줄 정의**: 라우트 데이터를 **메타데이터로 관리**한다.
> icon · path · scope 를 한 곳에서 정의하고, 코딩 중 추적·일관 변환·손쉬운 라우팅 관리를 제공한다.

## 왜 만드는가

라우트 정보가 흩어지면 같은 사실을 여러 곳에 중복해서 적게 된다 —
라우터 설정에 path, 메뉴 컴포넌트에 label 과 icon, 권한 체크에 또 path 문자열.
하나를 바꾸면 나머지를 찾아 고쳐야 하고, 문자열이라 **IDE 가 추적해주지 못한다.**

이 패키지는 **라우트 트리 하나를 단일 진실 공급원(SSOT)** 으로 두고 거기서 파생시킨다.

| 파생 대상   | 무엇                                       |
| ----------- | ------------------------------------------ |
| 라우터 설정 | React Router 가 먹을 수 있는 route objects |
| 네비게이션  | GNB · 사이드 메뉴 (icon · label 포함)      |
| 런타임 조회 | 현재 어느 라우트 노드에 있는지             |
| 이동        | 문자열이 아닌 **추적 가능한 참조**로 이동  |

## 현재 코드 자산

`packages/route-meta/src/`

| 모듈          | 역할                                          |
| ------------- | --------------------------------------------- |
| `types.ts`    | `RouteNode` 등 라우트 트리 타입               |
| `utils.ts`    | `buildRouteObjects` · `getNavigableRoutes` 등 |
| `hooks.ts`    | `useCurrentRouteNode` 등 런타임 매칭          |
| `renderer.ts` | 라우트 렌더러                                 |

기존 코드의 설계 의도 (index.ts 주석에 남아 있음, 재검토 대상):

- 모든 `RouteNode` 는 `path` 를 명시한다
- 자동화 계층 간 일관성을 위해 **절대 경로**를 쓴다
- React Router 의 index route 는 **의도적으로 쓰지 않는다**

회귀 테스트는 `utils.test.ts` 1개.

## 다음 할 일

`10_requirements.md` 작성. 그 문서에서 다음을 결정해야 한다.

| 결정할 것                                                                | 왜 먼저 정해야 하나                                                  |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| **`scope` 가 무엇을 뜻하는가** — 권한? 메뉴 표시 범위? 둘 다?            | 권한이라면 정책 주입이 필요하다. 패키지가 권한 체계를 정하면 안 된다 |
| **"코딩시 추적" 의 실체** — 타입 수준 추적을 어디까지 보장하나           | 리터럴 타입 추론이냐 제네릭이냐로 API 형태가 완전히 갈린다           |
| **"일관 변환" 이 변환하는 대상 목록**                                    | 파생 대상이 정해지지 않으면 무엇을 export 할지 정할 수 없다          |
| **React Router 결합도** — react-router-dom 전용인가, 어댑터로 뺄 것인가  | peerDeps 와 패키지 경계에 직접 영향                                  |
| 기존 3가지 정책(절대경로 · path 필수 · index route 금지)을 유지할 것인가 | 소비자에게 강제하는 제약이다. 근거가 남아 있어야 한다                |
