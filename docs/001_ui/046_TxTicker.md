## 개발 목적

저절로 움직이는 공지 줄. **멈출 수 있게 만드는 것**이 이 부품의 값이다 — 직접 짜면 대개 빠뜨리는데, 저절로 움직이는 것에는 멈출 수단이 있어야 한다(WCAG 2.2.2).

## 기능

### 쓰는 법

```tsx
// 세로 — 한 줄씩 올라간다
<TxTicker>
  <a href="/notice/1">점검 안내 — 9월 3일 02:00~04:00</a>
  <a href="/notice/2">새 기능이 추가되었습니다</a>
</TxTicker>

// 가로 — 끊임없이 흐른다
<TxTicker flow speed={40}>
  <span>BTC 62,145,000</span>
  <span>ETH 3,410,000</span>
</TxTicker>
```

**자식 하나가 항목 하나다.** 링크든 글자든 그대로 넣는다.

**멈출 수 있어야 저절로 움직여도 된다** (WCAG 2.2.2). 그래서 멈춤 버튼은 없앨 수 없다 —
`controls={false}` 는 화면에서 감출 뿐이고 Tab 이 닿으면 나타난다.
얹거나 초점이 가도 멈춘다 — 읽는 동안 지나가 버리면 안 된다.

**움직임을 줄여 달라고 한 사람에게는 멈춘 채로 시작한다.** 첫 항목이 그대로 서 있고,
보고 싶으면 재생을 누른다.

항목이 하나뿐이면 움직일 것이 없으므로 **버튼도 그리지 않는다.**

`controls={false}` 로 버튼을 **화면에서 감출 수 있다.** 없어지는 것은 아니라서
초점이 오면 나타난다 — 깨끗한 줄과 멈출 수 있음을 둘 다 가진다.

겉모습은 CSS 변수로 바꾼다 — `.tx-ticker { --tx-ticker-line: 2rem }`.

## 정한 것 · 고친 것

```tsx
// 세로 — 한 줄씩 올라간다
<TxTicker interval={4000}>
  <a href="/notice/1">점검 안내 — 9월 3일 02:00~04:00</a>
  <a href="/notice/2">새 기능이 추가되었습니다</a>
</TxTicker>

// 가로 — 끊임없이 흐른다
<TxTicker flow speed={40}>
  <span>BTC 62,145,000</span>
  <span>ETH 3,410,000</span>
</TxTicker>
```

정한 것들.

- **멈춤 버튼은 없앨 수 없다. 다만 화면에서 감출 수 있다** — `controls={false}`.
  처음에는 "끌 수 없다" 로 정했다가 **공지 한 줄만 두고 싶은 자리**를 위해 사용자가 옵션을
  요청해 다시 정했다. 감추되 **DOM 에서 빼지 않는 것**이 그 둘을 함께 가지는 길이다:
  화면에서는 사라지고 자리도 차지하지 않지만, **Tab 이 닿으면 제자리에 나타난다.**
  `display: none` 이면 키보드로 멈출 길이 통째로 사라져 WCAG 2.2.2 를 깬다.
  `TxAppShell` 의 건너뛰기 링크와 같은 방식이고(`:focus-visible` 이 아니라 `:focus`),
  얹거나 초점이 가면 멈추는 것도 그대로다
- **멈춤은 읽는 자리(`__viewport`)에만 건다.** 버튼까지 걸면 버튼에 손을 얹는 것만으로
  멈춰서, 눌러도 아무 일이 없는 것처럼 보인다
- **움직임을 줄여 달라고 한 사람에게는 멈춘 채로 시작한다** (사용자 결정). 못 보게 막는
  것이 아니라 시작하지 않을 뿐이라, 재생을 누르면 돈다. `useLayoutEffect` 로 잡아
  **한 프레임도 움직이지 않는다.** 설정이 꺼져도 되돌리지 않는다 — 손으로 멈춘 것을
  설정 변경이 덮으면 안 된다
- **가로는 시간이 아니라 속도(`speed`, 초당 픽셀)로 받는다.** 시간으로 받으면 항목이
  둘일 때와 열일 때의 읽는 속도가 달라진다. 폭을 재서(`ResizeObserver`) 시간을 낸다
- **두 재주가 한 컴포넌트다** (사용자 결정). 속은 다르지만 — 세로는 `transform` +
  전이, 가로는 애니메이션 — **멈춘다·움직임을 줄인다는 규약이 둘에게 같아서** 한 곳에서
  지키는 편이 낫다. 도는지 멈췄는지는 `[data-moving]` 하나가 쥔다
- **이어 붙인 복제본은 `inert` 다.** 같은 링크가 두 번 잡히면 안 된다

### `transitionend` 를 기다리면 안 되는 자리였다

세로는 이어 붙인 첫 줄까지 올라간 뒤 **소리 없이 제자리로 돌아와야** 한다(위로 되감으면
되돌아가는 것이 보인다). 처음에는 그 시점을 `transitionend` 로 잡았는데, **전이가 꺼져
있으면 그 이벤트가 영영 오지 않는다** — 그러면 끝을 지나 빈자리로 계속 올라간다.

`prefers-reduced-motion` 에서 우리가 직접 전이를 끄므로 **우리가 만든 자리**고, 애니메이션이
없는 환경도 마찬가지다. 실제로 Storybook 에서 색인이 17까지 올라가는 것을 보고 잡았다
(그 브라우저에서는 전이가 아예 돌지 않는다 — `TxAppShell` 때 적어 둔 도구 한계다).

이제 **CSS 에서 시간을 재 와서 그만큼 뒤에 돌린다.** 잴 수 없거나 전이가 없으면 `0` 이라
곧바로 넘어간다. 자리도 커스텀 프로퍼티가 아니라 **인라인 `transform`** 으로 준다 —
변수만 바꿨을 때 전이가 걸리는지는 브라우저를 탄다.

### 함께 고친 것 — `._*` 제외가 돌지 않았다

macOS 가 확장속성을 못 싣는 볼륨에 만드는 `._파일명` 부산물이 테스트로 잡혀 깨지는 것을
막으려고 `vitest.config.ts` 에 `exclude` 를 넣어 뒀는데, **`projects` 는 그 값을 물려받지
않는다.** 그래서 아무 일도 하지 않고 있었다. 두 프로젝트에 각각 적었다.
