## 2. 목적 — **더 이상 없다**

원래 목적은 "모든 tx-ui 컴포넌트가 같은 표면 색·테두리·hover 를 쓰게 하는 것" 이었다.
**그 일은 이제 `tokens.css` 의 `--tx-*` 전역 토큰이 한다** ([20_design §5](../20_design.md)).

두 방식의 차이가 폐기 사유 전부다.

|                 | `TxClass*` 상수                   | `--tx-*` 토큰                             |
| --------------- | --------------------------------- | ----------------------------------------- |
| 소비자가 바꾸기 | **못 바꾼다** — `export const` 다 | `:root` 한 줄                             |
| 필요한 도구     | **Tailwind**                      | 없음 (CSS·Sass·Tailwind·CSS Modules 무관) |
| 다크모드        | 값마다 `dark:` 짝을 손으로 붙인다 | `tokens.css` 의 `.dark` 한 곳             |
| hover·focus     | 별도 상수                         | 배경에서 파생 ([§5-1](../20_design.md))   |

## 3. 공개 API — **없다**

배럴(`src/index.ts`)에서 `export * from "./TxTheme"` 를 지웠다. 이 모듈의 공개 표면은 0이다.

**남은 파일은 내부 구현이다.** 아직 자체 CSS 로 옮기지 않은 컴포넌트 10종이 `*.theme.ts` 에서
상대 경로로 참조한다. 그 참조가 0이 되면 폴더를 지운다 (§7).

## 4. 커스터마이징 지점 — **없다**

값을 바꾸는 길은 `--tx-*` 토큰이다. 이 모듈은 그 길에 관여하지 않는다.

`packages/ui/src/index.test.ts` — **4개.** 컴포넌트 테스트가 아니라 **배럴 공개 표면 계약**이다.
