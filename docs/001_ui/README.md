# 001 — `@txstack/ui`

> **한 줄 정의**: 범용 UI 라이브러리. **쉬운 사용법과 쉬운 커스터마이징**을 제공하고,
> 여러 프로젝트에서 **동일한 사용 방법**을 보장해 멀티 작업을 쉽게 만든다.

## 왜 만드는가

프로젝트 A 와 B 를 번갈아 작업할 때, 같은 일을 하는 컴포넌트가 서로 다른 이름·다른 props 를 갖고 있으면
매번 다시 읽어야 한다. **이 라이브러리의 가치는 컴포넌트 개수가 아니라 "한 번 익히면 어디서든 통한다"는 것**이다.

그래서 이 패키지의 성공 기준은 세 가지다.

1. **쉬운 사용법** — 흔한 케이스는 props 없이도 동작한다
2. **쉬운 커스터마이징** — 벗어나는 케이스를 라이브러리를 포크하지 않고 처리할 수 있다
3. **동일한 사용 방법** — 컴포넌트 간 props·콜백 이름이 예측 가능하다

## 어떻게 진행하는가

**컴포넌트 하나가 작업 항목이다.** 그 하나를 6단계로 끝까지 올린다.

```
S1 문서(명세·감사) → S2 구현 → S3 테스트 → S4 스토리북 → 🧑 사용자 확인 → S5 문서사이트 → S6 에이전트가이드
```

- 규칙·완료 기준: [00_foundation/06_COMPONENT_FLOW.md](../00_foundation/06_COMPONENT_FLOW.md)
- 컴포넌트별 명세(S1): [components/](components/README.md) — **파일 이름 번호가 작업 순서다** (`01`~`26`)
- 진행 보드: [30_tasks.md](30_tasks.md) — 26 항목 × 6단계

기본 기능은 이미 구현되어 있다. 이 트랙의 실제 일은 **하나씩 열어보고 결함·불필요한 것을 정리해 올리는 것**이다.

## 상태

**파일럿 2종이 게이트까지 갔고, 거기서 방향이 하나 뒤집혔다.**

`TxSpinner`·`TxButton` 둘 다 S1~~S4 + 🧑 확인을 통과했다 (2026-08-25). 그 직후
[20_design](20_design.md) 에서 **스타일을 Tailwind 클래스 문자열에서 자체 CSS 로** 바꾸기로 하면서
**둘 다 `↩` 로 되돌렸다.** `S1`(명세·감사)은 유효하고 `S2`~~`S4` 를 새 방침으로 다시 돈다.

> **파일럿이 제 일을 한 것이다.** 24종에 박히기 전에 틀린 방향을 찾는 게 파일럿의 목적이다.
> 되돌린 작업이 아깝지만 **26종에 퍼진 뒤였다면 훨씬 비쌌다.**

**2차도 둘 다 끝났고 게이트를 통과했다** — `TxSpinner` 2026-08-25, `TxButton` 2026-08-26.
**파일럿이 닫혔다.** B 그룹의 `TxLoading` 이 그 규약으로 **`↩` 없이 S1~S4 + 게이트를 한 번에 통과했고** (2026-08-26),
`TxTheme` 은 **`❌` 폐기**로 끝났다. **A·B 그룹이 닫혔다 — 다음은 C 그룹이다.**
`TxLoading` 은 규약이 재사용된다는 첫 증거이고, `TxTheme` 은 **`❌` 가 정당한 결과라는 첫 사례**다.
`TxButton` 2차에서 **전역 토큰이 정해졌고**, 브라우저 실측이 **레이어 결함을 하나 더 잡아냈다.**
파일럿이 두 번 제 일을 한 셈이다 — 자세한 건 아래 "다음 할 일" 의 2)·3).

게이트도 제 일을 했다. 확인 과정에서 **4건이 나왔다** — 컨트롤이 죽어 있던 스토리,
`decorative` 가 소비자 `aria-label` 을 못 버리던 결함, `className` 으로 색이 반만 바뀌던 것,
커스터마이징 스토리가 하나로 뭉쳐 있던 것. **세 번째가 CSS 전환을 민 직접 증거였다.**
상세: [TxSpinner §12~§13](components/01_TxSpinner.md) · [TxButton §10](components/02_TxButton.md)

### 지금 유효한 전 패키지 결정

| 결정                                                                   | 파급                                       |
| ---------------------------------------------------------------------- | ------------------------------------------ |
| **스타일은 자체 CSS + `--tx-*` 토큰.** Tailwind 를 라이브러리에서 뺀다 | **26종 전부.** 각자의 S2 에서 옮긴다       |
| 선택자는 **`tx-*` 기본 클래스 + `data-*` 상태**, `data-tag` 는 유지    | 전 컴포넌트                                |
| 커스터마이징은 **CSS 변수 / `className` / `classNames`** 세 경로       | 전 컴포넌트                                |
| 타입 이름에 **`I` 접두를 쓰지 않는다**                                 | 전 패키지. 일괄 리네임 job `001-typenames` |
| 아이콘 크기는 **`1em` 기본 + `size?: number                            | string`**                                  | `size` 를 갖는 모든 컴포넌트의 선례 |
| 모션 저감(`prefers-reduced-motion`)은 **끄지 않고 늦춘다**             | 애니메이션이 있는 모든 컴포넌트            |
| **`.theme.ts` 는 만들지 않는다**                                       | 전 컴포넌트. 기존 18개는 S2 에서 제거      |
| **의미 prop 과 팔레트 prop 을 겹쳐 두지 않는다** (`color` 폐기)        | 같은 구조를 가진 컴포넌트                  |
| **`variant` 는 열어둔다** — CSS 로 `[data-variant="…"]` 를 늘리면 된다 | variant 를 가진 모든 컴포넌트              |

**폐기된 것** — `theme` prop · `TxThemeProvider` · `useTxTheme` · `themeMerge` · `TxClass*` 상수.
파일럿 2차에서 만들었지만 CSS 로 오면서 존재 이유를 잃었다. 경위: [TxButton §5 Q1](components/02_TxButton.md).

### 콜백 이름 규칙 — 그대로 유효하다

접미어는 타입 표시가 아니라 **"컴포넌트가 대신 해주는 일"** 이다 — `onChangeNumber={_age}` 처럼
세터를 그대로 꽂을 수 있는 게 그 값이다. 살리되 어휘를 닫는다. 표는 [20_design §7](20_design.md) 이 소유한다.

**적용은 각 컴포넌트의 S2 에서** — 공개 콜백 이름 변경은 컴포넌트마다 breaking change 라
테스트·스토리를 함께 고칠 수 있는 자리에서 한다.
