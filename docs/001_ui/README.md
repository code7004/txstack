# 001 — `@txstack/ui`

> **한 줄 정의**: 범용 UI 라이브러리. **쉬운 사용법과 쉬운 커스터마이징**을 제공하고,
> 여러 프로젝트에서 **동일한 사용 방법**을 보장해 멀티 작업을 쉽게 만든다.

## 왜 만드는가

프로젝트 A 와 B 를 번갈아 작업할 때, 같은 일을 하는 컴포넌트가 서로 다른 이름·다른 props 를 갖고 있으면
매번 다시 읽어야 한다. **이 라이브러리의 가치는 컴포넌트 개수가 아니라 "한 번 익히면 어디서든 통한다"는 것**이다.

그래서 이 패키지의 성공 기준은 세 가지다.

1. **쉬운 사용법** — 흔한 케이스는 props 없이도 동작한다
2. **쉬운 커스터마이징** — 벗어나는 케이스를 라이브러리를 포크하지 않고 처리할 수 있다
3. **동일한 사용 방법** — 컴포넌트 간 props·콜백 이름이 예측 가능하다

## 어떻게 진행하는가

**컴포넌트 하나가 작업 항목이다.** 그 하나를 6단계로 끝까지 올린다.

```
S1 문서(명세·감사) → S2 구현 → S3 테스트 → S4 스토리북 → 🧑 사용자 확인 → S5 문서사이트 → S6 에이전트가이드
```

- 규칙·완료 기준: [00_foundation/06_COMPONENT_FLOW.md](../00_foundation/06_COMPONENT_FLOW.md)
- 컴포넌트별 명세(S1): [components/](components/README.md)
- 진행 보드: [30_tasks.md](30_tasks.md) — 26 항목 × 6단계

기본 기능은 이미 구현되어 있다. 이 트랙의 실제 일은 **하나씩 열어보고 결함·불필요한 것을 정리해 올리는 것**이다.

## 상태

**파일럿 2종이 게이트까지 갔다.** `TxSpinner` S1~~S4 + 🧑 확인 통과 + S6 완료 ·
`TxButton` S1~~S4 완료, **🧑 확인 대기** — 2026-08-25.
둘 다 **S5 만 남았고 `903`(문서 사이트) 미정으로 ⏸ 보류다.**

게이트가 실제로 일했다. 확인 과정에서 **2건이 나와 통과 전에 고쳤다** — 컨트롤이 죽어 있던 스토리,
`decorative` 가 소비자 `aria-label` 을 못 버리던 결함. 후자는 S3 테스트가 조합을 안 짚어 놓친 것이다.
상세: [TxSpinner §12~§13](components/TxSpinner.md)

S1 에서 나온 **전 패키지 결정** (근거: [TxSpinner §5](components/TxSpinner.md#5-설계-결정-2026-08-25-합의))

| 결정                                                                      | 파급                                       |
| ------------------------------------------------------------------------- | ------------------------------------------ |
| 타입 이름에 **`I` 접두를 쓰지 않는다**                                    | 전 패키지. 일괄 리네임 job `001-typenames` |
| 아이콘 크기는 **`1em` 기본 + `size?: number \| string`** (폰트 크기 상속) | `size` 를 갖는 모든 컴포넌트의 선례        |
| 모션 저감(`prefers-reduced-motion`)은 **끄지 않고 늦춘다**                | 애니메이션이 있는 모든 컴포넌트            |
| `.theme.ts` 는 variant·slot 이 있을 때만. **없으면 만들지 않는다** (잠정) | `TxButton` 파일럿이 뒤집을 수 있음         |

`TxButton` S1 에서 나온 **커스터마이징 방침** (근거: [TxButton §5](components/TxButton.md#5-설계-결정-2026-08-25-합의--파일럿-2차의-본론))

| 결정                                                                                                  | 파급                                               |
| ----------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **커스터마이징은 3단** — `className`(이 하나) / `theme`(이 컴포넌트) / **`TxThemeProvider`(앱 전체)** | **26종 전부.** 나머지 24종은 각자 S2 에서 연결한다 |
| 병합 정책은 `"override"` — 소비자가 기본 스타일을 **끌 수 있어야** 한다                               | 전 컴포넌트                                        |
| **의미 prop 과 팔레트 prop 을 겹쳐 두지 않는다** (`color` 폐기)                                       | 같은 구조를 가진 컴포넌트                          |
| **`variant` 는 열어둔다** — `theme` 으로 키를 추가하면 그 이름을 쓸 수 있다                           | variant 를 가진 모든 컴포넌트                      |
| 컴포넌트 테마는 **공개 export** 한다 — 덮어쓰려면 모양을 알아야 한다                                  | 26종 중 15종은 이미 공개였다                       |

**콜백 이름 규칙도 확정했다** (근거: [TxButton §5 Q4](components/TxButton.md#q4--콜백-이름-규칙-추가-합의))

접미어는 타입 표시가 아니라 **"컴포넌트가 대신 해주는 일"** 이다 — `onChangeNumber={_age}` 처럼
세터를 그대로 꽂을 수 있는 게 그 값이다. 살리되 어휘를 닫는다.

| 접미어    | 넘어오는 것             |     | 금지                                 |
| --------- | ----------------------- | --- | ------------------------------------ |
| (없음)    | DOM 이벤트              |     | `Numb` · `Bool` · `Nums` (약어)      |
| `Text`    | `string`                |     | `Float` (`Number` 와 값이 같다)      |
| `Number`  | `number` (파싱)         |     | `onChangedText` (과거형)             |
| `Int`     | `number` (`Math.trunc`) |     | `*Internal` 을 공개 props 에 두는 것 |
| `Boolean` | `boolean`               |     |                                      |
| `Item`    | 항목 객체 전체          |     |                                      |
| `Value`   | 그 항목의 원시값        |     |                                      |

복수형은 배열을 뜻한다. **적용은 각 컴포넌트의 S2 에서** — 공개 콜백 이름 변경은 컴포넌트마다
breaking change 라 테스트·스토리를 함께 고칠 수 있는 자리에서 한다.
