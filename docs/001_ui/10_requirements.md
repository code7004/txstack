# 001 요구사항 — `@txstack/ui`

> **언제 확인하는가**: 컴포넌트를 살릴지 버릴지 판단할 때, 공개 API 를 늘리려 할 때, "완성"을 판정할 때.
> 확정: **2026-08-25** (파일럿 2종이 게이트를 통과한 뒤).
> **2026-08-25 갱신** — 스타일을 Tailwind 에서 CSS 로 바꾸면서 `R2`·`R4`·`R5` 와 §3 을 다시 썼다. 형태는 [20_design](20_design.md) 이 소유한다.

## 1. 무엇을 파는가

**컴포넌트 개수가 아니라 "한 번 익히면 어디서든 통한다" 를 판다.**

프로젝트 A 와 B 를 오갈 때 같은 일을 하는 컴포넌트가 다른 이름·다른 props 를 가지면 매번 다시 읽어야 한다.
그 인지 비용을 없애는 게 이 패키지의 존재 이유다. **컴포넌트를 많이 만드는 것은 목표가 아니다.**

## 2. 요구사항

검증 가능한 형태로만 적는다. "좋게 만든다" 같은 건 요구사항이 아니다.

| ID  | 요구사항                                                                        | 어떻게 확인하나                                           |
| --- | ------------------------------------------------------------------------------- | --------------------------------------------------------- |
| R1  | **흔한 케이스는 props 없이 동작한다**                                           | 각 컴포넌트 S1 §6 의 "흔한 케이스" 예제가 props 0~1개     |
| R2  | **커스터마이징은 세 경로** — CSS 변수 / `className` / `classNames`              | [20_design §4](20_design.md). 세 경로가 겹치지 않음       |
| R3  | **이름이 예측 가능하다** — `Tx` 접두 · `<Name>Props` · 콜백 어휘 6종            | `20_design.md` 규약. 새 컴포넌트가 규약을 벗어나지 않음   |
| R4  | **소비자가 어떤 스타일 방식을 쓰든 된다** — CSS · Sass · Tailwind · CSS Modules | 아래 §3. 빈 프로젝트에서 import 한 줄로 렌더 + 값 변경    |
| R5  | 다크모드는 **`.dark` 클래스 전략** — 토큰 재정의로만 따라온다                   | Storybook 테마 토글로 확인                                |

`R6` 의 상세(peer 의존, 앱 전역 금지, 의존 방향)는 아키텍처 문서가 소유한다. 여기서 중복하지 않는다.

## 3. 스타일 전달 방식 (R4)

### 그때 무엇이 문제였나

Tailwind 클래스 문자열로 스타일을 쓰던 시절, 소비자는 자기 CSS 에 이 한 줄을 넣어야 했다.

```css
@source "../node_modules/@txstack/ui/dist";
```

**빠뜨리면 클래스가 전부 purge 되어 스타일이 하나도 안 남는다.** 증상(아무 스타일 없음)이
원인(스캔 경로 누락)을 전혀 가리키지 않는, 이 패키지에서 가장 잘 밟는 지뢰였다.

### 결정: **자체 CSS 로 전환한다** — 제약이 근원적으로 사라진다

처음엔 "사전 빌드 CSS 를 동봉해 `@source` 만 막자" 로 정했었다. 그러나 그건 **증상만 막는다** —
소비자가 **커스터마이징하려면 여전히 Tailwind 가 필요**했다. 그래서 한 단계 더 갔다.

```tsx
import "@txstack/ui/styles.css"; // 한 번만
```

```css
:root {
  --tx-color-primary: #7c3aed; /* Tailwind 없이도 앱 전체 테마가 바뀐다 */
}
```

- `@source` 는 **더 이상 존재하지 않는다.** 안내할 함정 자체가 없어졌다
- **소비자의 스타일 방식을 묻지 않는다** — CSS · Sass · Tailwind · CSS Modules 어느 쪽이든 `className` 은 통한다
- **이건 소비자 쪽 요구사항이다.** 라이브러리 소스를 무엇으로 쓰는지(= 평문 CSS)와는 별개고,
  배포물은 어느 쪽이든 CSS 라 소비자는 차이를 모른다 → [20_design §2-1](20_design.md)
- 대가와 버린 대안은 [20_design §2](20_design.md) 가 소유한다. 여기서 중복하지 않는다

### 구현할 때 주의할 것 (`001-styles-css` job)

- 컴포넌트별 `<Name>.css` 를 모아 **`dist/styles.css` 하나로** 낸다. 컴포넌트가 CSS 를 import 하지 않는다
- `package.json` 의 `files`·`exports` 에 넣어야 실제로 올라간다 → `npm pack --dry-run` 으로 확인
- **토큰 이름은 공개 API 다.** 지우거나 바꾸면 major

## 4. 수용 기준 — 무엇이 되면 완성인가

> **남긴 컴포넌트 전부가 🧑 사용자 확인 게이트까지 통과한다.**

- **26종을 다 살릴 의무는 없다.** S1 감사에서 "범용성이 없다" 로 판정되면 `❌` 폐기가 정답이다
- 통과 기준은 [06_COMPONENT_FLOW](../00_foundation/06_COMPONENT_FLOW.md) 의 `S1`~`S4` + 게이트
- 게이트 뒤의 `S5`·`S6` 는 완성 판정에 넣지 않는다 — **`903` 사이트가 서기 전에는 물리적으로 불가능**하기 때문이다

### 수용 기준에 넣지 않은 것

빼기로 한 것도 적어 둔다. 나중에 "왜 이건 안 봤지" 를 다시 논의하지 않으려고.

| 넣지 않은 것         | 이유                                                                            |
| -------------------- | ------------------------------------------------------------------------------- |
| 배포 가능 상태       | 배포는 **되돌릴 수 없어** 별도 판단이다. `npm publish` 는 명시적 요청으로만     |
| 접근성 최소선        | **각 컴포넌트 S1 감사에 접근성 절이 이미 있다.** 전역 게이트로 또 두면 중복이다 |
| 에이전트 가이드 검증 | `904` 가 소유한다. 표본이 몇 종 더 쌓여야 판정이 의미를 갖는다                  |

## 5. 범위 밖 — 하지 않는 것

**요청이 와도 하지 않는다.** 여기 있는 것을 하려면 이 문서를 먼저 고친다.

| 하지 않는 것        | 왜                                                                                                       |
| ------------------- | -------------------------------------------------------------------------------------------------------- |
| **폼 상태 관리**    | 검증·에러 메시지·제출 흐름을 소유하지 않는다. `react-hook-form` 을 쓰는 소비자와 싸우게 된다             |
| **국제화(i18n)**    | 문구는 **영어 기본값 + prop 교체**로만. 번역 체계를 갖지 않는다 (`TxSpinner` 의 `aria-label` 이 그 방식) |
| **아이콘 세트**     | `TxIcons` 를 범용 아이콘 라이브러리로 키우지 않는다. **내부에서 쓰는 것만** 둔다                         |
| **애니메이션 체계** | 전환 효과를 목표로 삼지 않는다. 모션 저감 대응과 기본 전환까지만                                         |
