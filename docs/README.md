# docs

V 모델 기준 문서 구조. 상세 규약은 루트 `CLAUDE.md` 의 "문서 구조" 절 참고.

| 폴더            | 성격                                            | 파일명         |
| --------------- | ----------------------------------------------- | -------------- |
| `rules/`        | 항상 따르는 아키텍처·컨벤션·가드레일. 상시 유효 | `NN_TITLE.md`  |
| `requirements/` | 원 요청·요구사항 정의 (무엇을/왜)               | `nnn_title.md` |
| `plans/`        | 작업사항 = 구현 계획 (어떻게)                   | `nnn_title.md` |
| `verification/` | 검증 = 테스트 계획·수행·결과 (제대로 됐나)      | `nnn_title.md` |
| `reports/`      | 산출물 = 메신저 전달 요약 + 작업 종합           | `nnn_title.md` |

하나의 요구사항은 같은 번호 `nnn` 을 공유한다: 요구사항 → 작업사항 → 검증 → 산출물.
