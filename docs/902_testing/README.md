# 902 — Vitest / 테스트 방향

> **한 줄 정의**: **안정화된 테스트 방향**을 제시한다.

## 왜 만드는가

라이브러리는 앱과 다르다. **소비자가 우리 코드를 신뢰할 근거가 테스트뿐**이다.
동시에, 라이브러리 테스트는 쉽게 과잉이 된다 — 구현 세부를 테스트하면 리팩터링마다 테스트가 깨지고,
그러면 테스트를 지우게 된다.

그래서 이 트랙의 목표는 "커버리지 숫자"가 아니라 **"무엇을 테스트하고 무엇을 테스트하지 않는지에 대한 합의"** 다.

## 현재 코드 자산

- vitest `^3`, 설정은 루트 `vitest.config.ts` 가 소유
- 패키지별로 환경이 갈린다 — `network` 는 node, React 가 붙은 것은 jsdom
- `@testing-library/react` · `@testing-library/dom` · `jsdom` 설치됨
- 테스트 파일 **4개** (패키지당 1개)

| 파일                                    | 대상            |
| --------------------------------------- | --------------- |
| `packages/ui/src/tx-ui.utils.test.ts`   | ui 유틸만       |
| `packages/hooks/src/hooks.test.tsx`     | 훅              |
| `packages/route-meta/src/utils.test.ts` | route-meta 유틸 |
| `packages/network/src/client.test.ts`   | client          |

**컴포넌트 자체를 렌더링해서 검증하는 테스트는 없다.**

## 상태

**미착수 (`10_requirements.md` 없음). 단, 파일럿 1차의 실측 결과가 나와 있다.**

### 파일럿 1차 `TxSpinner` S3 에서 관찰된 것 (2026-08-25)

`001-TxSpinner-S3` 에서 이 저장소의 **첫 컴포넌트 렌더 테스트**를 썼다 (13개).
아래는 `902-01`~`902-05` 의 🤝 결정에 직접 재료가 되는 관찰이며, **결정 자체는 아니다.**

**1) jsdom 은 CSS 결함을 볼 수 없다 — `902-04` 에 직결.**
`TxSpinner` 의 최대 결함 D1 은 "`w-full` 클래스가 `width` 속성을 CSS 캐스케이드에서 이긴다" 였다.
`width` 속성을 확인하는 테스트를 썼더니 **결함을 되살려도 통과했다.** jsdom 에 Tailwind CSS 가 없으니
그 승부가 아예 일어나지 않는다. 회귀 감시를 **"기본 클래스에 크기 유틸이 없다"** 로 바꿔서야 잡혔다.

> 시사점: 컴포넌트 테스트는 **렌더 결과(픽셀·계산된 스타일)가 아니라 그 결과를 만드는 입력**
> — 속성·클래스·ARIA — 을 지키는 데 쓰는 편이 낫다. 겉모습은 `901`/브라우저 검증의 몫이다.
> `902-04` 와 "901 과 중복되는 영역" 문제의 경계선이 여기서 한 번 그어졌다.

**2) 통과는 근거가 아니다.** 13개 중 회귀를 실제로 잡은 건 처음엔 1개뿐이었다.
결함을 하나씩 **주입해서** 확인하고 나서야 나머지를 고칠 수 있었다. 최종적으로 5개 주입 전부 잡히고,
**주입마다 정확히 1개만 깨진다**(과결합 없음). → 완료 판정 기준 후보 (`902-01`)

**3) 환경 분기를 확장자로 갈랐다.** `ui` 는 유틸과 컴포넌트가 한 패키지에 섞여 있다.
패키지째 jsdom 으로 옮기면 유틸이 DOM 에 기대는지가 가려지므로 `vitest.config.ts` 에서
`*.test.ts` → node / `*.test.tsx` → jsdom 으로 나눴다. → `902-02` 재료

**4) 도입하지 않은 것.** `@testing-library/jest-dom` (속성·클래스 확인엔 기본 matcher 로 충분).
RTL 자동 cleanup 은 `globals` 를 켜야 등록되므로 `afterEach(cleanup)` 을 파일에서 직접 붙였다.

실물: `packages/ui/src/TxSpinner/TxSpinner.test.tsx` · 배경은 [TxSpinner §11](../001_ui/components/TxSpinner.md)
