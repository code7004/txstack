이 트랙의 산출물은 **에이전트가 읽고 옳게 코드를 쓰는지**로만 검증된다. 문서 리뷰로는 부족하다.

`904-03` 이후 실제 확인 절차를 `40_verification.md` 에 정한다. 후보 —

- 빈 프로젝트에서 가이드만 주고 컴포넌트를 쓰게 해본다
- 있지도 않은 prop(`variant="primary"` 류)을 발명하는지 본다
- Tailwind `@source` 설정을 스스로 넣는지 본다
