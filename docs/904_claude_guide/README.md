# 904 — 에이전트 가이드 (에이전트용 사용 설명)

> **한 줄 정의**: 타 프로젝트의 **에이전트가 이 라이브러리를 정확히 쓰도록** 하는 가이드.
> **문서 사이트에서 내려받아 쓴다** — npm 에 동봉하지 않는다 (2026-08-25 재결정, 아래 참고).

## 왜 필요한가

사람용 문서와 에이전트용 문서는 다르다.

| 사람이 필요한 것           | 에이전트가 필요한 것                                        |
| -------------------------- | ----------------------------------------------------------- |
| 왜 이렇게 설계했는지, 배경 | **시그니처 · 규칙 · 금지사항** (서술은 오히려 방해)         |
| 훑어보고 감을 잡기         | 정확한 import 경로, 정확한 props 이름                       |
| 예제를 보고 응용           | **복사해서 그대로 쓸 수 있는 최소 예제**                    |
| "대충 이런 거구나"         | **하지 말아야 할 것** (있지도 않은 prop 을 만들어내지 않게) |

에이전트가 가장 많이 하는 실수는 **그럴듯한 API 를 발명하는 것**이다.
`<TxButton variant="primary">` 처럼, 있을 것 같지만 없는 prop 을 쓴다.
가이드의 첫 번째 목적은 그걸 막는 것이다.

## 도달 경로 — **동봉하지 않는다** (2026-08-25 재결정)

> **이전 판은 "패키지에 동봉해서 배포한다 (확정)" 이었다. 뒤집었다.**

**문서 사이트에서 내려받아 쓴다.** 소비자가 파일을 자기 프로젝트에 두고, 자기 `CLAUDE.md` 에서 가리킨다.

```
소비자 프로젝트/
├─ CLAUDE.md            ← "@txstack/ui 를 쓸 때는 아래 파일을 먼저 읽는다" 한 줄
└─ docs/txstack-ui.agents.md   ← 사이트에서 받아 둔 것
```

### 왜 동봉을 뺐나

**동봉해도 어차피 자동으로 안 읽힌다.** Claude Code 는 `node_modules/*/CLAUDE.md` 를 자동 로드하지 않는다.
소비자가 자기 `CLAUDE.md` 에서 가리켜야 하는 건 **동봉이든 다운로드든 똑같다.**
그렇다면 동봉으로 얻는 게 크지 않고, 패키지 무게와 `files` 관리 부담만 남는다.

### 대신 잃는 것 — 버전 일치

동봉의 유일한 실질 이점이 **설치된 버전과 가이드 버전이 자동으로 맞는 것**이었다.
다운로드로 가면 소비자가 `v2` 가이드를 받아 `v1` 을 쓰는 상황이 생긴다.

> **`903` 에 넘기는 요구사항: 가이드를 버전별로 받을 수 있어야 한다.** 최신 하나만 두면 이 문제가 남는다.

### 소스는 코드 옆에 둔다

`packages/ui/AGENTS.md` — 패키지 폴더 안이지만 `files` 에 없으므로 **npm 에는 실리지 않는다**
(`npm pack --dry-run` 으로 확인함). 코드 옆에 둬야 컴포넌트를 고칠 때 같이 갱신된다.
`docs/` 아래로 빼면 코드와 멀어져서 어긋난다.

사이트는 이 파일을 그대로 서빙한다. **복사 파이프라인을 만들지 않는다.**

## 현재 상태

**파일럿 2종 수록 (2026-08-25)** — `packages/ui/AGENTS.md` 에 `TxSpinner`·`TxButton`. `001-TxSpinner-S6`·`001-TxButton-S6` 산출물.

`904-01`·`904-02`·`904-04` 가 이때 결정됐다.

| 결정        | 내용                                                                                       |
| ----------- | ------------------------------------------------------------------------------------------ |
| 파일명      | **`AGENTS.md`** — 벤더 중립. 어차피 소비자가 직접 가리켜야 하니 벤더명을 박을 이유가 없다  |
| 원본 위치   | **패키지 폴더 안**(`packages/ui/AGENTS.md`), `files` 밖. 복사 파이프라인 없음              |
| 담을 것     | **사용 방법만.** 시그니처 전량 수록은 하지 않는다 — 아래 참고                              |
| 소비자 연결 | 사이트 다운로드 + **프로젝트 `CLAUDE.md` 에 넣을 한 줄**                                   |
| 게재 기준   | **게이트를 통과한 컴포넌트만** 싣는다. 검증 안 된 API 를 에이전트에게 사실처럼 주지 않는다 |

### 담을 것 — "타입이 못 하는 말만"

`dist/index.d.ts` 가 이미 패키지에 들어간다. **시그니처를 문서에 베끼면 갱신 지점이 둘이 되고 갈린다** —
실제로 changeset 하나가 `ITxSpinnerProps` 로 어긋나 있었다. 타입은 빌드마다 자동으로 맞지만 문서는 사람이 고쳐야 한다.

그래서 가이드는 **타입이 말해주지 못하는 것**에 집중한다.

- **필수 설정** — 특히 Tailwind `@source`. 빠뜨리면 스타일이 전부 사라진다
- **언제 쓰나 / 언제 다른 걸 쓰나** — `TxSpinner` vs `TxLoading` vs `TxButton`
- **함정** — `size="w-6"` 처럼 타입은 통과하지만 무효인 것
- **하지 말 것** — 없는 prop 발명, 서브패스 임의 생성, `dist` 직접 import
- props 표는 **자주 쓰는 것만** 요약하고, "전체는 `.d.ts` 를 보라" 로 넘긴다

### 아직 안 된 것

**배포 경로가 `903` 문서 사이트에 물려 있다.** 사이트가 없으면 소비자가 받을 곳이 없다.
파일 자체는 완성돼 있으므로, `903` 이 서면 서빙만 붙이면 된다.
