# 400. `@txstack/network` (트랙 4)

- 로드맵: [ROADMAP](../ROADMAP.md) · 제품 정의: [000 §2-2](000_product_definition.md)
- 하위 트랙: [4-1 축소](../plans/401_network_reshape.md) · [4-2 문서](../plans/402_network_docs.md)
- **2026-08-19 재정의됨** — HTTP 클라이언트에서 **axios 플러그인 모음**으로 성격을 바꾼다

## 배경 / 목적

원래 의도는 세 가지였다 — 보일러플레이트 감소 · 로그 강화 · 에러 핸들링.

의도 자체는 코드에 실재했으나, 대조 결과 **대부분이 "주입 가능한 형태로 포장된 프로젝트 종속"**
이었다. 봉투·인증·401·에러 형태·페이지네이션 규약이 전부 특정 백엔드를 전제하고 있었고,
소비자는 값만 채울 수 있었다. 상세와 근거는 [000 §2-2](000_product_definition.md).

**원본 3개 저장소의 백엔드 규약이 서로 다르다.** 봉투·인증·401 은 애초에 공유될 수 없는 것이었다.

그래서 이 패키지는 **클라이언트를 자처하지 않는다.** 클라이언트는 소비자가 `axios.create` 로
만들고, 백엔드 규약과 무관하게 반복되는 것만 여기서 제공한다.

## 범위

**포함**

| 대상          | 왜 범용인가                                                                       |
| ------------- | --------------------------------------------------------------------------------- |
| 로깅 인터셉터 | 소요 시간 · 민감 필드 마스킹 · 그룹 로그. 백엔드 규약과 무관하게 매번 손으로 짠다 |
| 에러 정규화   | `http` / `network` / `timeout` / `canceled` 판별. axios 를 쓰면 누구나 겪는다     |

**제외** — 응답 봉투 해제 · 인증 헤더 · 401 처리 · 싱글턴 · 재시도 · 토큰 만료 판정 ·
서버 응답/에러 타입. 전부 소비자가 자기 인터셉터로 한다.

## 요구사항 (수용 기준)

| ID  | 요구사항                      | 수용 기준                                                                     |
| --- | ----------------------------- | ----------------------------------------------------------------------------- |
| N1  | 백엔드 규약 가정이 0 이다     | 봉투·에러 형태·인증 방식·페이지네이션을 전제하는 export 가 없다               |
| N2  | 로그 목적지를 소비자가 정한다 | `console` 이 하드코딩되지 않는다. 로거를 주입한다                             |
| N3  | 마스킹이 실제로 가린다        | 중첩 객체·배열 안의 민감 필드도 가려진다                                      |
| N4  | 실패 종류를 구분한다          | 네트워크 끊김·타임아웃·취소·HTTP 에러가 서로 다른 값으로 나온다               |
| N5  | React 비의존이 유지된다       | react 미설치 환경에서 테스트가 통과한다 (**완료**)                            |
| N6  | 사용법을 문서에서 볼 수 있다  | "이 패키지가 하지 않는 것" 이 먼저 나오고, 소비자가 붙일 인터셉터 예제가 있다 |

## 영향 범위

- `packages/network` — **공개 API 의 대부분이 제거된다.** 11개 export → 3~4개
- `apps/playground` 의 `/network` 화면 — 전면 재작성
- 배포물: 미배포 상태라 소비자 마이그레이션은 없다. changeset 은 남긴다
- 트랙 9-3(역이식): 3개 저장소가 각자 인터셉터를 갖게 된다. 그것이 정상이다

## 제약 / 비고

- `axios` 는 **필수 peer** 다.
- 걷어낸 코드를 버리지 않는다 — 봉투/인증/401 인터셉터의 **레시피**는 문서에 남긴다.
  각 프로젝트가 복사하되, 복사본이 갈라져도 문제가 없는 종류(프로젝트마다 달라야 하는 것)다.
- ESM 전용 정책은 [rules 03](../rules/03_PUBLISHING_AND_VERSIONING.md) 을 따른다.
  축소 후에도 Node 백엔드(CJS) 사용 요구가 남는지는 4-2 에서 확인한다.
