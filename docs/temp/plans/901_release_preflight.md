# 9-1. 배포 사전 점검

- 요구사항: [900 배포](../requirements/900_release.md) — P1 · P2
- 선행: **트랙 0~4 의 `-1` · `-2` 하위 트랙이 전부 닫힌 뒤**
- 상태: 대기 (게이트 미충족)

## 목표

되돌릴 수 없는 작업 직전에, 되돌릴 수 있는 것들을 전부 확인한다.

## job

| ID    | job                                            | 담당 | 완료 기준                                                                |
| ----- | ---------------------------------------------- | ---- | ------------------------------------------------------------------------ |
| P1-01 | npm scope `txstack` 선점 여부 확인             | 🧑   | npmjs.com 에서 확인. **선점돼 있으면 패키지명 4개와 모든 문서가 바뀐다** |
| P1-02 | npm org(또는 사용자명) 생성                    | 🧑   | `npm whoami` 로 확인되고 scope 에 publish 권한이 있다                    |
| P1-03 | 트랙 게이트 점검표 작성                        | 🤖   | 0~4 의 `-1`·`-2` job 이 전부 닫혔는지 한 장으로 확인된다                 |
| P1-04 | 소비자 실검증(`0-3`) 전체 통과 확인            | 🤖   | 최신 코드로 한 번 더 돌린다                                              |
| P1-05 | 4종 `npm pack --dry-run` 파일 목록 최종 확인   | 🤖   | 불필요한 파일 0건. 크기가 예상 범위                                      |
| P1-06 | README 4종의 설치·예제가 최신인지 확인         | 🤖   | 개명·API 변경이 전부 반영돼 있다                                         |
| P1-07 | LICENSE·`repository`·`homepage` 필드 최종 확인 | 🤖   | 4종 + 루트 전부 채워져 있다                                              |
| P1-08 | 미사용 changeset 정리                          | 🤖   | 쌓인 changeset 이 의도한 버전 증가와 맞는지 확인                         |

## 검증

`P1-03` 의 점검표가 이 트랙의 산출물이다. **하나라도 열려 있으면 9-2 로 넘어가지 않는다.**

## 비고

`P1-01` 을 **가장 먼저** 한다. scope 를 못 쓰면 나머지 job 의 산출물(README 예제, import 경로,
문서 전체)이 다시 바뀐다. 실제로 `@txkit` 은 이미 선점돼 있어 `@txstack` 으로 정했던 이력이 있다.
