- 선행: 3-1 · 3-2
- 상태: 대기

## job

| ID    | job                                              | 담당 | 완료 기준                                                            |
| ----- | ------------------------------------------------ | ---- | -------------------------------------------------------------------- |
| R3-01 | 브레드크럼 파생 유틸이 필요한지 판단             | 🤝   | 같은 트리에서 뽑을 수 있는 세 번째 파생물. 넣을지 정한다             |
| R3-02 | 라우트 메타에 임의 필드를 붙이는 확장점 검토     | 🤝   | `meta` 를 제네릭으로 열지, 고정 필드로 둘지 정한다                   |
| R3-03 | lazy 라우트(코드 스플리팅) 패턴 문서화 또는 지원 | 🤖   | playground 가 쓰는 `lazy` + `Suspense` 패턴이 문서나 유틸로 정리된다 |
| R3-04 | 라우트 트리 검증 유틸 (경로 중복·오타 탐지)      | 🤝   | 개발 중에 잘못된 트리를 일찍 잡아줄지 판단                           |
| R3-05 | React Router 버전 호환 범위 확인                 | 🤖   | peer 범위(`>=6`)가 실제로 6·7 모두에서 도는지 확인                   |

## 검증

## 비고

이 패키지는 **작게 유지하는 것이 미덕**이다. 라우팅 프레임워크를 만들려는 것이 아니라,
정의 하나에서 파생시키는 패턴을 제공하는 것이 목적이다. 기능 추가는 보수적으로 판단한다.
