# 003 — `@txstack/hooks`

> **한 줄 정의**: `useUrlQuery` 로 **URL params 를 손쉽게 읽고 쓴다.**

## 왜 만드는가

목록 화면의 상태(페이지, 검색어, 필터, 정렬)는 URL 에 있어야 한다. 그래야 새로고침·뒤로가기·링크 공유가 된다.
그런데 `useSearchParams` 를 직접 쓰면 매번 같은 잡일을 반복한다 —
문자열 파싱, 숫자·불리언 변환, 빈 값 제거, 기본값 처리, 여러 값을 한 번에 갱신.

`useUrlQuery` 는 **URL 을 `useState` 처럼 쓰게** 만든다.

## 현재 코드 자산

`packages/hooks/src/`

| 훅                  | 위치                                  | 비고                 |
| ------------------- | ------------------------------------- | -------------------- |
| `useUrlQuery`       | `useUrlQuery.ts` → `/router` 서브패스 | **이 패키지의 핵심** |
| `useObjectChanged`  | `useObjectChanged.ts`                 | 범위 재검토 대상     |
| `useSafePolling`    | `useSafePolling.ts`                   | 범위 재검토 대상     |
| `useStateForObject` | `useStateForObject.ts`                | 범위 재검토 대상     |

**서브패스 분리 구조**: 라우터가 필요한 `useUrlQuery` 는 `@txstack/hooks/router` 에 있다.
루트 배럴을 `react-router-dom` 과 분리해, 다른 라우터(Next.js, TanStack Router)를 쓰는 소비자도
이 패키지를 설치할 수 있게 한 것. **이 구조를 유지할지도 재검토 대상이다.**

테스트는 `hooks.test.tsx` 1개.
