# 00. dev-guide 와 다른 점

> 언제 보나: dev-guide 의 규칙이 이 프로젝트에서 그대로인지 확인할 때.

적용 버전: `@txstack/dev-guide` <0.x.y>. **여기 없는 것은 dev-guide 그대로다.**

| dev-guide 규칙                                  | 이 프로젝트                                       | 이유 · 결정                                       |
| ----------------------------------------------- | ------------------------------------------------- | ------------------------------------------------- |
| <예: 커밋은 요청할 때만 (rules/commits.md 3장)> | <검사 · 빌드가 통과하면 AI 가 스스로 커밋 · 푸시> | <YYYY-MM-DD 사용자 결정 — 사용자는 검수를 맡는다> |
